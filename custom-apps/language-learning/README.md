# 星语学园 (language.learning)

内嵌于 `doremy.float.phone` 的陪伴式、养成系多语种学习 App。

## 核心特性
- **多语种词元/词条/词族三级词库**：第一版默认内置英语 (EN)、日语 (JA)、俄语 (RU)、韩语 (KO)，支持在界面内动态新增任意语种。
- **五维独立复习引擎**：拼写默写、听力辨词、例句完形、词义辨析、AI 同人小剧场独立计分，互不覆盖。
- **AI 同人小剧场（双模生成）**：支持「模板快速生成（零 Token）」与「AI 专属生成（调用所选角色人设）」，同一词族自动轮换不同记忆场景。
- **星光值轻养成与商店**：每日签到、免签休息日、补签机制、防挂机真实学习任务，以及带重复玩偶转碎片保底的星光兑换商店。
- **零代码可视化美化**：右上角内置「🎨 美化」面板，支持一键切换 5 套主题配色、替换背景壁纸、更换商品图片与自定义 CSS。
